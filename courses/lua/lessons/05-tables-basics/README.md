# Урок 05. Таблицы — сердце Lua

## 🎯 Цель
Понять единственную структуру данных Lua, отличие массива от словаря, итераторы и главные ловушки (`nil`, `#`).

## 📖 Теория

### 1. Таблица — всё сразу
В Lua нет отдельных массива, словаря, объекта, множества. Есть **таблица** — и она умеет всё:

```lua
local t = {}                        -- пустая таблица
local arr = {10, 20, 30}            -- таблица-массив
local dict = {name = "Алекс", age = 20}  -- таблица-словарь
local mixed = {10, 20, name = "x"}  -- можно смешивать (но обычно не надо)
```

Ключом может быть почти что угодно (кроме `nil`), значением — что угодно (кроме `nil` — он удаляет).

### 2. Массивы: индексация с 1!
```lua
local fruits = {"яблоко", "груша", "слива"}
print(fruits[1])   --> яблоко (ПЕРВЫЙ индекс — 1, не 0!)
print(fruits[3])   --> слива
print(fruits[10])  --> nil (выход за границы — просто nil, без ошибки)
print(#fruits)     --> 3 (длина массива)

fruits[4] = "персик"  -- добавить в конец
fruits[#fruits + 1] = "абрикос"  -- идиома добавления в конец
```

> ⚠️ Индексация с 1 — самый частый источник ошибок у пришедших из других языков.
> `arr[0]` не упадёт, а тихо вернёт `nil` (или ранее записанное туда — отдельная ловушка!).

### 3. Словари и сахар `t.key`
```lua
local user = {name = "Алекс", age = 20}
print(user.name)      --> Алекс (сахар для user["name"])
print(user["age"])     --> 20
user.city = "СПб"     -- добавить поле
user.age = nil        -- удалить поле

-- когда ключ не «слово» — только квадратные скобки:
local t = {}
t["имя с пробелом"] = 1
t[42] = "число-ключ"
t[true] = "булев ключ"
```

### 4. Обход: `ipairs` vs `pairs`
```lua
local arr = {"a", "b", "c"}
for i, v in ipairs(arr) do   -- СТРОГО по порядку 1..n, только массивная часть
  print(i, v)
end

local dict = {name = "А", age = 20}
for k, v in pairs(dict) do   -- ВСЕ ключи, порядок НЕ ГАРАНТИРОВАН
  print(k, v)
end
```

Правило: массив — `ipairs` (или числовой `for`), словарь — `pairs`.
`pairs` на массиве тоже сработает, но порядок может сюрпризить. `ipairs` на словаре
с нечисловыми ключами просто ничего не найдёт.

### 5. Главные ловушки таблиц
```lua
-- ЛОВУШКА 1: nil в середине массива ломает # и ipairs
local bad = {1, nil, 3}
print(#bad)  --> может быть 1 или 3! Неопределённость. Никогда так не делай.

-- ЛОВУШКА 2: таблицы — по ссылке, а не по значению
local a = {1, 2, 3}
local b = a        -- b указывает на ТУ ЖЕ таблицу!
b[1] = 999
print(a[1])        --> 999 (!). Копия — только руками или функцией copy.

-- ЛОВУШКА 3: сравнение таблиц — по ссылке
print({1,2} == {1,2})  --> false! Разные объекты.
```

### 6. Библиотека `table`
```lua
local t = {3, 1, 2}
table.sort(t)                    --> {1, 2, 3} (сортирует НА МЕСТЕ!)
table.insert(t, "в конец")       -- добавить
table.insert(t, 1, "в начало")   -- вставить по позиции
local x = table.remove(t)        -- убрать и вернуть последний
print(table.concat({"а","б","в"}, ", "))  --> а, б, в (склейка!)
table.move(a, 1, #a, 1, b)       -- копирование диапазона (5.3+)
```

### 7. Конструкторы: короткий и длинный синтаксис
```lua
local point = {x = 10, y = 20}     -- коротко
local point2 = {["x"] = 10, ["y"] = 20}  -- то же самое длинно
```

### 8. Матрица = таблица таблиц
```lua
local m = {
  {1, 2, 3},
  {4, 5, 6},
}
print(m[2][3])  --> 6 (2-я строка, 3-й столбец)
```

## ✅ Запомнить
- Таблица — единственная структура. Индексы массива — с 1.
- `t.k` = `t["k"]`. Присваивание `nil` удаляет ключ.
- `ipairs` — массивы по порядку, `pairs` — всё без порядка.
- `nil` в массиве, копирование по ссылке, `==` по ссылке — три ловушки.
- `table.sort/insert/remove/concat` — must know.
