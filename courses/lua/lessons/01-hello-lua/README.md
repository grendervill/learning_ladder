# Урок 01. Hello, Lua! Первый запуск

## 🎯 Цель
Понять, что такое Lua, запустить интерпретатор и свой первый файл, научиться выводить текст и писать комментарии.

## 📖 Теория

### 1. Что такое Lua?
Lua — маленький, быстрый скриптовый язык. Его встраивают в игры (World of Warcraft, Roblox, Factorio),
в редакторы (Neovim), в прошивки и серверы (Nginx + OpenResty). Философия Lua — **«механизм, а не политика»**:
язык даёт тебе несколько мощных кирпичиков (таблицы, функции, замыкания), а как строить — решаешь ты.

Интересные факты:
- Название «Lua» — по-португальски «луна». Пишется именно `Lua`, а не `LUA`.
- Создан в 1993 году в Бразилии, в PUC-Rio.
- Весь интерпретатор — около пары сотен килобайт. Поэтому он живёт там, где Python не влезет.

### 2. REPL — твой калькулятор и песочница
REPL (Read–Eval–Print Loop) — интерактивный режим. Набери в терминале:

```bash
lua
```

и жми Enter. Появится приглашение `>`. Теперь можно экспериментировать:

```lua
> print("Привет, Луна!")
Привет, Луна!
> 2 + 3 * 4
14
> "а" .. "б"
аб
```

Выход: `Ctrl+D` (на macOS/Linux) или `Ctrl+Z`, затем Enter (на Windows).

> 💡 **Совет ментора:** REPL — место для экспериментов. Не понял теорию — иди в REPL и проверь руками за 5 секунд. Это привычка профи.

### 3. Первая программа
Создай файл `hello.lua`:

```lua
print("Привет, Lua!")
```

Запуск:

```bash
lua hello.lua
```

Что происходит: интерпретатор читает файл сверху вниз, выполняет каждую инструкцию.
`print` — встроенная функция: принимает сколько угодно значений, выводит их через табуляцию и переводит строку.

```lua
print("Привет", 42, true)  --> Привет    42    true
print()                    --> (просто пустая строка)
```

### 4. Комментарии
```lua
-- это однострочный комментарий

--[[
   это многострочный комментарий,
   может занимать несколько строк
]]
```

Комментарии не выполняются. Пиши их, чтобы объяснить **почему**, а не **что** (что — и так видно из кода).

### 5. Числа и арифметика (краткий предпросмотр)
Подробно — в уроке 02, а пока знай: в Lua есть `+ - * / % ^` и скобки.
Есть особенность: `^` — это возведение в степень, а не XOR!

```lua
print(2 + 3 * 4)   --> 14
print((2 + 3) * 4) --> 20
print(2 ^ 10)      --> 1024.0
print(10 % 3)      --> 1 (остаток от деления)
```

### 6. Типичные ошибки новичка
| Ошибка | Что видишь | Что делать |
|---|---|---|
| `lua: cannot open hello.lua: No such file` | не тот каталог | проверь `pwd` и `ls`, перейди в нужную папку |
| `print "hello"` без скобок | работает, но | пока всегда пиши скобки `print(...)` |
| Забыл закрыть кавычку | `unfinished string near ...` | закрой кавычку в той же строке |

## ✅ Что нужно запомнить
- `lua` без аргументов — REPL, `lua файл.lua` — запуск файла.
- `print(...)` выводит значения и переводит строку.
- `--` — комментарий до конца строки, `--[[ ]]` — многострочный.
- Ошибки интерпретатора — твой друг: читай текст после `lua:` — там имя файла, номер строки и причина.
