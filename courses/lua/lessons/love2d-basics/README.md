# LÖVE 2D: первые шаги

## 🎯 Цель
Запустить первое окно на LÖVE, понять три главных функции `love.load`, `love.update` и
`love.draw`, научиться рисовать фигуры и текст, задавать цвет и оживлять картинку
движением. К концу урока у тебя будет маленькая сцена, которая работает сама.

## 📖 Теория

### 1. Что такое LÖVE
LÖVE (произносится «лав») — это бесплатный движок для игр и графики на Lua. Ты пишешь
обычный Lua-код, а LÖVE открывает окно и рисует в нём то, что ты попросишь. Никаких
меню и кнопок «создать проект»: вся игра — это один или несколько `.lua`-файлов.

Точка входа — файл `main.lua`. Именно его LÖVE запускает первым.

> В нашем курсе есть **браузерный предпросмотр** — уменьшенная копия LÖVE прямо на
> странице задания. Он понимает **подмножество API**: `love.load`, `love.update`,
> `love.draw`, `love.graphics.setColor`, `clear`, `rectangle`, `circle`, `line`,
> `print`, `polygon`, `love.timer.getDelta`, `love.keypressed` и `love.mousepressed`.
> Этого хватает для всех заданий урока. Для полной версии — с настоящими шрифтами,
> спрайтами, звуком и всеми модулями — скачай движок на **love2d.org** и запусти
> папку с игрой через `love .`.

### 2. Три функции, на которых держится всё
LÖVE сам вызывает твои функции в нужный момент. Тебе не нужно писать цикл — движок
уже его крутит. Ты только заполняешь «дырочки»:

```lua
function love.load()
  -- вызывается ОДИН раз при старте: готовим переменные, грузим картинки
  x = 100
end

function love.update(dt)
  -- вызывается КАЖДЫЙ кадр ДО рисования: двигаем объекты, считаем логику
  x = x + 60 * dt
end

function love.draw()
  -- вызывается КАЖДЫЙ кадр: рисуем то, что должно быть на экране
  love.graphics.rectangle("fill", x, 100, 40, 40)
end
```

Порядок в каждом кадре всегда один и тот же: **`load` (один раз) → `update` →
`draw` → `update` → `draw` → ...**

- В `load` задай начальные значения: позиции, цвета, счёт.
- В `update` меняй числа — здесь живёт «физика» игры.
- В `draw` **только рисуй**. Не меняй здесь переменные — иначе анимация начнёт
  зависеть от частоты кадров и запутается.

### 3. Координаты: начало в левом верхнем углу
Окно LÖVE — это система координат, где:

- `x` растёт **вправо**,
- `y` растёт **вниз** (а не вверх, как на уроках математики!),
- точка `(0, 0)` — **левый верхний** угол.

Представь лист бумаги, на котором пишут слева направо и сверху вниз — как текст.
Поэтому «выше» на экране — это **меньше** `y`, а «ниже» — **больше** `y`.

Размер окна по умолчанию в предпросмотре — **800×450** пикселей. Значит, правый
нижний угол — примерно `(800, 450)`.

### 4. Цвет: четыре числа от 0 до 1
Цвет задаётся функцией `love.graphics.setColor(r, g, b, a)`:

- `r`, `g`, `b` — красный, зелёный, синий, каждый от `0` до `1`;
- `a` — прозрачность (alpha), тоже `0..1`; `1` — непрозрачный.

```lua
love.graphics.setColor(1, 0, 0)        -- чистый красный
love.graphics.setColor(0, 1, 0)        -- зелёный
love.graphics.setColor(0.5, 0.5, 1)    -- светло-синий
love.graphics.setColor(1, 1, 1, 0.5)   -- белый, наполовину прозрачный
```

Важная деталь: **цвет «залипает»**. Он остаётся таким, пока ты не вызовешь
`setColor` снова. Поэтому порядок такой: сначала `setColor`, потом рисуем.

Чтобы очистить экран и залить его фоном, есть `love.graphics.clear(r, g, b)`:

```lua
function love.draw()
  love.graphics.clear(0.1, 0.1, 0.15)  -- тёмно-синий фон
  love.graphics.setColor(1, 1, 1)
  -- ... рисуем поверх
end
```

### 5. Фигуры
Основные фигуры принимают первым аргументом **режим**: `"fill"` (заливка) или
`"line"` (контур).

```lua
-- прямоугольник: (x, y) — левый верхний угол, дальше ширина и высота
love.graphics.rectangle("fill", 50, 50, 120, 60)
love.graphics.rectangle("line", 50, 50, 120, 60)

-- круг: (x, y) — ЦЕНТР, затем радиус
love.graphics.circle("fill", 400, 200, 60)
love.graphics.circle("line", 400, 200, 60)

-- линия: список координат x1, y1, x2, y2, ... (можно много точек подряд)
love.graphics.line(0, 0, 800, 450)
love.graphics.line(100, 400, 200, 300, 300, 350)

-- многоугольник: режим и таблица точек
love.graphics.polygon("fill", {400, 100, 450, 200, 350, 200})
```

Обрати внимание: у прямоугольника точка — **угол**, а у круга — **центр**. Это самая
частая путаница у новичков.

### 6. Текст
Текст рисуется функцией `love.graphics.print(text, x, y)`:

```lua
love.graphics.setColor(1, 1, 1)
love.graphics.print("Привет, LÖVE!", 20, 20)
love.graphics.print("Счёт: " .. score, 20, 50)
```

Второй и третий аргументы — координаты. Числа к тексту приклеиваются через
конкатенацию `..` (не забудь `tostring` для сложных случаев, хотя `..` сам приводит
число к строке).

### 7. Анимация и время кадра (`dt`)
Наивный способ «двигать» объект — `x = x + 1` каждый кадр. Беда в том, что на быстром
компьютере кадров в секунду больше, и объект поедет быстрее. Правильный способ —
умножать скорость на **`dt`** — время, прошедшее с прошлого кадра, в секундах:

```lua
function love.update(dt)
  x = x + 200 * dt   -- 200 пикселей в СЕКУНДУ, независимо от частоты кадров
end
```

`dt` берётся из `love.timer.getDelta()` — но в `update` он уже приходит готовым
аргументом. Если нужен он где-то ещё (например, в `draw`), вызови
`love.timer.getDelta()`.

Запомни правило: **все скорости умножаем на `dt`**. Тогда при 30 и при 120 кадрах в
секунду объект пройдёт одинаковое расстояние за одинаковое время.

### 8. Ввод с клавиатуры и мыши
LÖVE вызывает твои функции-обработчики, когда пользователь что-то нажимает:

```lua
function love.keypressed(key)
  -- key — строка: "left", "right", "space", "up", "escape" и т.д.
  if key == "space" then
    jump()
  end
end

function love.mousepressed(x, y, button)
  -- x, y — координаты клика, button — 1 (левая) или 2 (правая)
  print("клик в " .. x .. ", " .. y)
end
```

`keypressed` срабатывает **один раз** в момент нажатия, а не каждый кадр. Если нужно
плавное движение при удержании — обычно читают состояние клавиши, но в нашем
предпросмотре достаточно `keypressed`: по нажатию меняем переменную, а в `update`
плавно догоняем её.

Имена клавиш: стрелки — `"left"`, `"right"`, `"up"`, `"down"`, пробел — `"space"`,
выход — `"escape"`. В предпросмотре кликни по холсту, чтобы он ловил нажатия.

### 9. Типичные ошибки
| Ошибка | Причина |
|---|---|
| Экран пустой | забыл `love.graphics.clear` или рисуешь за пределами 0..800 / 0..450 |
| Всё одного цвета | не вызвал `setColor` перед фигурой — цвет «залип» от прошлой |
| Объект летит с разной скоростью | умножил на `dt` не всё или забыл про `dt` вовсе |
| `attempt to perform arithmetic on a nil value` | переменную не объявили в `love.load` |
| Круг не там, где ожидал | перепутал центр круга и угол прямоугольника |

## ✅ Запомнить
- LÖVE вызывает `love.load` (один раз), затем `love.update(dt)` и `love.draw` каждый кадр.
- Начало координат — левый верхний угол; `x` вправо, `y` вниз.
- Цвет — четыре числа `0..1`; `setColor` действует до следующего вызова.
- `rectangle` — угол + ширина/высота; `circle` — центр + радиус; режим `"fill"`/`"line"`.
- Текст: `love.graphics.print(text, x, y)`.
- Любую скорость умножаем на `dt`, чтобы анимация не зависела от кадров.
- Ввод: `love.keypressed(key)` и `love.mousepressed(x, y, button)`.
