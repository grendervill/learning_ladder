# Домик из фигур

Нарисуй домик на фоне собственного цвета.

## Что сделать
1. В `love.draw` очисти экран `love.graphics.clear(...)` каким-нибудь тёмным цветом.
2. Нарисуй **стены** — прямоугольник `love.graphics.rectangle("fill", x, y, w, h)`.
3. Нарисуй **крышу** — многоугольник `love.graphics.polygon("fill", { ... })` (треугольник).
4. Нарисуй **солнце** — круг `love.graphics.circle("fill", x, y, r)` где-то в углу.

## Подсказки
- Сначала вызови `love.graphics.setColor(r, g, b)`, потом рисуй фигуру — цвет «залипает».
- Окно предпросмотра 800×450, координаты начинаются в левом верхнем углу.
- У прямоугольника первая точка — угол, у круга — центр.

## Проверка
Нажми «запустить» в предпросмотре: должны появиться фон, стены, треугольная крыша и круг.
