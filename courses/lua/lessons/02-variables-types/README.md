# Урок 02. Переменные и типы данных

## 🎯 Цель
Понять 8 типов Lua, зачем нужен `local`, чем конкатенация отличается от сложения, как читать ввод.

## 📖 Теория

### 1. Переменные: global vs local
```lua
x = 10        -- ГЛОБАЛЬНАЯ переменная (видна везде; так делать не надо!)
local y = 20  -- ЛОКАЛЬНАЯ (видна только в своём блоке; так делать надо)
```

**Правило №1 в Lua: всегда пиши `local`, если нет веской причины для глобала.**
Глобалы засоряют общее пространство, из-за них сложно искать ошибки. Позже (урок 11)
узнаешь, что глобалы вообще-то живут в таблице `_G`.

### 2. Восемь типов и функция `type`
Всего типов 8: `nil`, `boolean`, `number`, `string`, `table`, `function`, `userdata`, `thread`.
Сейчас нам важны первые четыре + таблица (её разберём в уроке 05).

```lua
print(type(nil))            --> nil
print(type(true))           --> boolean
print(type(42))             --> number
print(type("hello"))        --> string
print(type({}))             --> table
print(type(print))          --> function
```

`type(x)` возвращает **строку** с именем типа — удобно для проверок.
Раз это строка, её можно сравнивать:
```lua
if type(x) == "number" then print("это число") end
```

Отсюда следует `type(type(42)) == "string"`: внутренний вызов `type(42)`
возвращает строку `"number"`, а внешний определяет тип этой строки — `string`.
Цепочка: число → строка → строка. Запомни: **результат `type` — всегда строка**,
поэтому `type` чего угодно, кроме... нет, вообще всегда `string` на втором уровне.

Почему `type({})` — это `table`, а не `array`? Потому что в Lua **нет отдельных
массивов как типа**: массивы, словари, объекты — всё строится из одного
кирпичика, таблицы (подробно разберём в уроке 05). Фигурные скобки `{}` всегда
создают именно таблицу, поэтому `type` так и отвечает. Правило простое:
видишь `{}` — это `table`, а массивом она становится по способу использования
(ключи `1, 2, 3...`).

### 3. `nil` — «ничего»
`nil` означает отсутствие значения. Неприсвоенной переменной равен `nil`:

```lua
print(несуществующая)  --> nil
local a
print(a)               --> nil
```

Присвоение `nil` **удаляет** значение:
```lua
local t = {}
t.key = "значение"
t.key = nil  -- ключ исчез
```

### 4. Числа
В Lua 5.3+ числа делятся на целые (`integer`) и дробные (`float`), но думать об этом
обычно не нужно — арифметика «просто работает»:

```lua
local int = 10        -- integer
local flt = 10.5      -- float
print(10 / 4)         --> 2.5  (обычное деление ВСЕГДА даёт float)
print(10 // 4)        --> 2    (целочисленное деление //)
print(2 ^ 0.5)        --> 1.414... (корень — степень 0.5)
```

Запись чисел: `1e3` = 1000, `0xFF` = 255 (шестнадцатеричное).

### 5. Строки
Строки — в двойных, одинарных кавычках или длинных скобках:

```lua
local s1 = "привет"
local s2 = 'мир'
local s3 = [[многострочная
строка "с любыми" 'кавычками' внутри]]
```

Главные операции:
```lua
print("а" .. "б")      --> аб        (.. — СКЛЕЙКА строк, конкатенация)
print(#"привет")       --> 6         (# — длина в БАЙТАХ!)
print("5" + 1)        --> 6         (Lua сам превратит строку в число для +)
print("5" .. 1)       --> 51        (а число в строку — для ..)
```

> ⚠️ **Ловушка с `#`:** длина считается в **байтах**, а не в буквах!
> Кириллица в UTF-8 занимает 2 байта на букву: `#"привет"` = 12, а не 6.
> Про подсчёт букв — в уроке 06 (там есть `utf8.len`).

### 6. Булевы значения и truthiness
```lua
local t = true
local f = false
```

**Главное правило Lua:** ложны только `false` и `nil`. Всё остальное — истина,
включая `0` и `""` (пустую строку)! Это отличается от Python/JS, заруби на носу:

```lua
if 0 then print("0 — правда!") end      --> напечатается!
if "" then print("пусто, но правда") end --> напечатается!
if nil then print("не напечатается") end
```

А что с необъявленной или объявленной-но-неприсвоенной переменной?
```lua
local x   -- объявили, значения не дали
print(x)  --> nil (переменная без значения — это nil!)
if x then print("да") end  --> молчит: nil — это ложь
```
Отсюда цепочка: **нет значения → `nil` → ложь**. Поэтому «необъявленная»
переменная тоже ложна — не потому что она «пустая» или «нулевая», а потому что
её значение `nil`, а `nil` — одна из двух ложных вещей в языке. Это касается и
`local x` без присваивания: ей автоматически достаётся `nil`.

### 7. Ввод с клавиатуры
```lua
print("Как тебя зовут?")
local name = io.read()   -- читает строку до Enter
print("Привет, " .. name .. "!")
```

`io.read()` возвращает строку. Нужно число? Преобразуй: `tonumber(io.read())`.
Обратное преобразование: `tostring(42)` → `"42"`.

### 8. Типичные ошибки
| Ошибка | Причина |
|---|---|
| `attempt to perform arithmetic on a nil value` | переменная не присвоена / опечатка в имени |
| `attempt to concatenate a nil value` | склейка `..` с `nil` |
| Сравнение `==` строки с числом всегда false | `"5" == 5` → false, типы разные! |

## ✅ Запомнить
- Всегда `local`. `type(x)` — узнать тип. Типов 8.
- `nil` — отсутствие значения; `false` и `nil` — единственная ложь.
- `..` склеивает, `+` складывает. `#` — длина в байтах.
- Ввод: `io.read()` (строка), числа — через `tonumber`.
