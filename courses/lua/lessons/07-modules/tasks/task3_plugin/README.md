# Мини-система плагинов

Урок 07, задание 3. Программа загружает плагины по именам из командной строки и вызывает у каждого функцию `run()`. Каждый плагин — отдельный модуль в подпапке `plugins/`.

## Файлы

- `main.lua` — загрузчик плагинов (допиши его).
- `plugins/hello.lua` — плагин-приветствие (допиши).
- `plugins/shout.lua` — плагин, печатающий текст верхним регистром (допиши).

## Задание

1. Допиши `plugins/hello.lua`: `local M = {}`, функция `M.run()` печатает приветствие, `return M`.
2. Допиши `plugins/shout.lua`: функция `M.run(text)` печатает `text` через `string.upper`, а без аргумента — дефолтную громкую фразу.
3. Допиши `main.lua`: для каждого имени из `arg` (`for i = 1, #arg`) сделай `require("plugins." .. имя)`. Точка в имени означает подпапку.
4. Обработай ошибки через `pcall(require, name)`: нет такого плагина → `Нет плагина: <имя>, пропускаю`; нет функции `run` → `Плагин <имя> без run(), пропускаю`.
5. Придумай и добавь третий плагин сам (время, кубик, цитата — на выбор).
6. Ответь комментарием в `main.lua` на вопрос: почему `require` кэширует модули и когда кэш вреден?

## Как запускать

Запускай из папки задания, чтобы `require` нашёл `plugins/`:

```bash
cd lessons/07-modules/tasks/task3_plugin && lua main.lua hello shout
```

Ожидаемый вывод:

```text
[hello] Привет от плагина!
[shout] ЭТО ГРОМКИЙ ПЛАГИН!
```
