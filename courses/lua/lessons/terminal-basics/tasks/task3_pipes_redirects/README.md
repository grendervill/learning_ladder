# Задание 3. Конвейер и сохранение результата

Финальное задание урока: собрать пайп, отфильтровать вывод и сохранить его в файл,
а потом отдельно поймать ошибку. Работай в терминале задания.

## Шаги
1. Создай несколько файлов с разными именами, например три-четыре, среди которых хотя бы
   два начинаются одинаково (например `report.txt` и `report-old.txt`).
2. Выведи список файлов каталога и передай вывод по пайпу в фильтр, который оставит
   только строки со словом `report`.
3. Сохрани отфильтрованный результат в файл `found.txt` так, чтобы файл создавался заново
   (перезапись), а не дополнялся.
4. Проверь, что записалось: прочитай файл `found.txt`.
5. Допиши в конец `found.txt` ещё одну строку с текстом `готово`, не стирая прежнее содержимое.
6. Попробуй вывести несуществующий каталог так, чтобы сообщение об ошибке ушло в файл
   `errors.txt`, а не на экран. Затем посмотри, что в `errors.txt`.
7. Узнай код возврата последней команды и объясни, почему он не равен нулю.

## Что нужно понять
- Как `|` передаёт stdout одной команды на stdin другой.
- Разницу между `>` и `>>`.
- Как `2>` перенаправляет только поток ошибок, и что такое `$?`.

## Критерий готовности
У тебя есть файл `found.txt` с отфильтрованными именами и дописанной строкой, файл
`errors.txt` с текстом ошибки, и ты понимаешь, почему код возврата после неудачной команды
был ненулевым.
