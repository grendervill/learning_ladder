# Задание 2. Прогулка по каталогам и обратно

Ты умеешь смотреть по сторонам. Теперь научись перемещаться: создавать каталоги и ходить
внутрь и наружу. Выполняй шаги по порядку, после каждого шага проверяй себя командой,
показывающей текущий каталог.

## Шаги
1. Создай каталог с именем `notes`.
2. Войди в него.
3. Убедись, что ты действительно внутри `notes`.
4. Создай внутри ещё один каталог — `drafts`.
5. Войди в `drafts`, затем поднимись обратно в `notes` через родительский каталог.
6. Вернись в исходный каталог задания, не используя длинный абсолютный путь
   (подсказка: `cd -` или `..`).
7. Убедись, что ты вернулся, и что каталог `notes/drafts` существует.

## Что нужно понять
- Чем относительный путь отличается от абсолютного.
- Как `..` поднимает на уровень вверх, а `cd -` возвращает в предыдущий каталог.
- Почему `cd notes` работает только если `notes` лежит в текущем каталоге.

## Критерий готовности
Ты создал структуру `notes/drafts`, прошёлся по ней вниз и вверх и вернулся в стартовый
каталог, ни разу не написав полный путь от корня.
