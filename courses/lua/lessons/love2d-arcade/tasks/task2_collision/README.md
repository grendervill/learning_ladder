# Поймай цель

Сделай так, чтобы игрок ловил цель: при столкновении прямоугольников счёт растёт,
а цель переставляется в новое место.

## Что сделать
1. В `love.load` заведи игрока и цель как таблицы с полями `x, y, w, h`, а также `score = 0`.
2. Напиши функцию `hit(ax, ay, aw, ah, bx, by, bw, bh)` — проверку AABB.
3. В `love.update(dt)` двигай цель вниз (`coin.y = coin.y + 120 * dt`) и, когда она
   уходит за низ, возвращай её наверх.
4. Если `hit(...)` вернула true — увеличь `score` и переставь цель.
5. В `love.keypressed` двигай игрока стрелками `left`/`right`.

## Подсказки
- AABB: перекрытие по x **и** по y.
- `math.random(0, 770)` даёт случайную x-координату цели.
- Счёт рисуй через `love.graphics.print("Счёт: " .. score, 20, 20)`.

## Проверка
Двигай игрока стрелками и лови падающий квадрат — счёт должен увеличиваться.
