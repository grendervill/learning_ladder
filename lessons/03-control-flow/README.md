# Урок 03. Управление потоком: ветвления и циклы

## 🎯 Цель
Научиться ветвить (`if`) и повторять (три вида циклов), понять границы циклов `for`.

## 📖 Теория

### 1. `if` — ветвление
```lua
local age = 20
if age >= 18 then
  print("совершеннолетний")
elseif age >= 14 then       -- elseif пишется СЛИТНО (не else if!)
  print("подросток")
else
  print("ребёнок")
end
```

Условия — любые выражения. Помни truthiness из урока 02: `if 0` — истина!

Операторы сравнения: `==` `~=` (не равно! именно тильда) `<` `>` `<=` `>=`.
Логические: `and` `or` `not`.

```lua
-- проверка диапазона:
if age >= 18 and age < 65 then print("трудоспособный") end
-- значение по умолчанию через or (идиома!):
local name = io.read()
name = name ~= "" and name or "Гость"  -- если пусто — "Гость"
```

> 💡 Идиома `x = cond and a or b` — это тернарный оператор по-луашному.
> Работает, только если `a` не `false`/`nil`. Запомни, встретишь в чужом коде.

### 2. `while` — цикл с предусловием
```lua
local i = 1
while i <= 5 do
  print(i)
  i = i + 1   -- НЕ ЗАБУДЬ шаг, иначе бесконечный цикл!
end
```

### 3. `repeat ... until` — цикл с постусловием
Выполняется **хотя бы один раз** (проверка в конце):
```lua
local n
repeat
  print("Угадай число 7:")
  n = tonumber(io.read())
until n == 7
```

### 4. Числовой `for` — главный цикл Lua
```lua
for i = 1, 10 do        -- от 1 до 10 включительно, шаг 1
  print(i)
end

for i = 10, 1, -2 do    -- от 10 до 1, шаг -2: 10, 8, 6, 4, 2
  print(i)
end

for i = 0, 1, 0.2 do    -- дробный шаг тоже можно
  print(i)
end
```

Форма: `for var = start, stop, step do`. Граница `stop` **включительна**!
(Пришедшие из Python ждут `range(10)` = 0..9 — в Lua `for i = 1, 10` = 1..10.)

> ⚠️ Счётчик цикла — неявный `local`. Менять его внутри тела — плохая идея,
> поведение может удивить. Нужен свой счётчик — заведи отдельную переменную.

### 5. Обобщённый `for` (предпросмотр)
Полную силу покажем в уроке 05, а синтаксис запомни сейчас:
```lua
local fruits = {"яблоко", "груша", "слива"}
for index, value in ipairs(fruits) do
  print(index, value)
end
```

### 6. `break` и `goto`
```lua
for i = 1, 100 do
  if i * i > 50 then
    print("первый квадрат > 50:", i * i)
    break   -- выйти из цикла
  end
end
```
`break` выходит только из **одного** (внутреннего) цикла.

`goto` в Lua есть, но ментор запрещает использовать без крайней нужды:
спагетти-код читается ужасно. Узнаешь о нём — и забудешь. 🙂

### 7. Типичные ошибки
| Ошибка | Причина |
|---|---|
| `unexpected symbol near '='` в условии | написал `=` вместо `==` |
| Бесконечный `while` | забыл шаг `i = i + 1` |
| Цикл `for i = 10, 1 do` ничего не делает | шаг по умолчанию +1, а надо -1 при убывании |
| `else if` двумя словами | в Lua слитно: `elseif` |

## ✅ Запомнить
- `~=` — не равно. `elseif` — слитно. Граница `for` включительна.
- `while` может не выполниться ни разу, `repeat` — минимум один раз.
- `cond and a or b` — идиома «тернарника». `break` — выход из цикла.
