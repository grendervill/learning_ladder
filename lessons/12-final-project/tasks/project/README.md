# Финальный проект

Урок 12. Здесь ты собираешь всё, чему научился за лестницу, в одно законченное приложение.

## Выбери вариант

- **А. 🕹️ Подземелье** — текстовый roguelike: карта, игрок, монстры, бои, ключ и выход.
- **Б. ✅ Таск-трекер PRO** — развитие урока 07: приоритеты, теги, дедлайны, сохранение в файл.
- **В. 🌐 Мини-веб** — HTTP-парсер, роутер, файловый сервер (или TCP на LuaSocket).

Можно предложить свой вариант — согласуй его с ментором до начала работы.

## Требования

1. **Модульность** — минимум 3 файла-модуля плюс главный (`main.lua`).
2. **ООП** — хотя бы один класс с наследованием или метаметодами.
3. **Обработка ошибок** — `assert` на границах и `pcall` там, где падает пользовательский ввод.
4. **Файлы** — сохранение и загрузка состояния между запусками.
5. **Корутины или итераторы** — там, где уместно (анимация, генерация, планировщик).
6. **README проекта** — как запускать, какие команды, пример сессии.

## Этап 0

Прежде чем писать код, опиши в этом `README.md` (или отдельной заметке): что строишь, структуру файлов и как запускать. Покажи ментору — архитектуру согласуем до реализации.

Дальше — итерациями: каркас → логика → сохранение → polish. Каждый этап — на проверку.

## Как запускать

Запускай из папки задания, чтобы `require` находил модули:

```bash
cd lessons/12-final-project/tasks/project && lua main.lua
```
