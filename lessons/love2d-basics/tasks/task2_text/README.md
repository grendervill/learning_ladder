# Заголовок и счётчик

Выведи на экран заголовок и число из переменной.

## Что сделать
1. В `love.load` заведи переменную `score` (например, `score = 0`).
2. В `love.draw` очисти экран и установи белый цвет.
3. Выведи заголовок `love.graphics.print("Моя игра", 20, 20)`.
4. Выведи счёт, склеив текст и число: `love.graphics.print("Счёт: " .. score, 20, 50)`.

## Подсказки
- `..` склеивает строку и число — `tostring` писать не обязательно.
- Не забудь `setColor(1, 1, 1)` перед текстом, иначе он унаследует прошлый цвет.

## Проверка
В предпросмотре должны быть видны две строки текста: заголовок и «Счёт: 0».
