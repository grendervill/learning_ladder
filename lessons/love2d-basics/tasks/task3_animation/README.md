# Движущийся круг

Оживи круг: пусть он едет вправо и отражается от края окна.

## Что сделать
1. В `love.load` задай `x = 60` и `speed = 200` (пикселей в секунду).
2. В `love.update(dt)` сдвигай круг: `x = x + speed * dt`.
3. Если `x` выходит за правый край (больше 800), верни его влево или поменяй знак скорости.
4. В `love.draw` очисти экран и нарисуй круг в позиции `x`.

## Подсказки
- Скорость умножаем на `dt` — иначе движение зависит от частоты кадров.
- Ширина окна предпросмотра — 800, высота — 450.
- Чтобы отражать движение, меняй знак: `speed = -speed`.

## Проверка
После запуска круг должен плавно ехать по экрану и не улетать за его пределы.
