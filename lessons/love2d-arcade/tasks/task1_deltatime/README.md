# Скорость в пикселях в секунду

Двигай квадрат со скоростью ровно 200 пикселей в секунду и отражай его от краёв.

## Что сделать
1. В `love.load` задай `x = 40`, `y = 210`, `speed = 200`.
2. В `love.update(dt)` сдвинь квадрат: `x = x + speed * dt`.
3. Отражай от краёв окна (ширина 800, размер квадрата 40): когда `x > 760`
   или `x < 0` — меняй знак `speed`.
4. В `love.draw` нарисуй квадрат в позиции `x`.

## Подсказки
- Умножай именно на `dt` — иначе скорость зависит от частоты кадров.
- Чтобы квадрат не вылезал, помни про его ширину: правый край — `x + 40`.
- Знак скорости меняется так: `speed = -speed`.

## Проверка
Квадрат должен плавно ходить туда-обратно и не выходить за пределы окна.
