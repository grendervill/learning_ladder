# Меню → игра → финал

Собери мини-игру на состояниях: меню, игра и экран проигрыша.

## Что сделать
1. В `love.load` задай `state = "menu"` и обнули `score`.
2. В `love.update(dt)` обновляй логику **только** когда `state == "play"`:
   двигай падающую цель, лови столкновение, копи счёт. Если цель ушла за низ —
   переходи в `state = "gameover"`.
3. В `love.draw` рисуй разное для каждого состояния:
   - `menu` — подсказку «Нажми пробел, чтобы начать»;
   - `play` — игрока, цель и счёт;
   - `gameover` — «Игра окончена» и итоговый счёт.
4. В `love.keypressed`: пробел в меню начинает игру и сбрасывает цель;
   в игре стрелки двигают игрока.

## Подсказки
- Начни `update` с проверки: `if state ~= "play" then return end`.
- Вынеси сброс цели в отдельную функцию `resetCoin()`, чтобы не повторяться.
- Пробел — это `key == "space"`.

## Проверка
Сначала видно меню; по пробелу начинается игра; при промахе появляется финальный
экран; можно вернуться в меню и начать заново.
