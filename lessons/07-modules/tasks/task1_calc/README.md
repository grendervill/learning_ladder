# Модуль-калькулятор

Урок 07, задание 1. Практика модулей: код разнесён на два файла, один из них подключает другой через `require`.

## Файлы

- `calc.lua` — твой модуль (файл 1 из 2). Здесь ты пишешь код.
- `main.lua` — готовая проверяющая программа (файл 2 из 2). **Не меняй её.**

## Задание

Допиши модуль `calc.lua`: реализуй и положи в таблицу `M` четыре функции.

- `M.add(a, b)` — сложение.
- `M.sub(a, b)` — вычитание.
- `M.mul(a, b)` — умножение.
- `M.div(a, b)` — деление. При делении на ноль функция должна вернуть **два** значения: `nil` и сообщение `"деление на ноль"`.

Не забудь в конце модуля `return M` — без этого `require` вернёт `true` вместо таблицы.

## Как запускать

Запускай из папки задания, чтобы `require("calc")` нашёл файл:

```bash
cd lessons/07-modules/tasks/task1_calc && lua main.lua
```

`main.lua` сам вызовет каждую функцию и напечатает `OK` или `FAIL`. Все `OK` — задание принято.
