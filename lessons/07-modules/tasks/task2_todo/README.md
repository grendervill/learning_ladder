# Менеджер задач: модуль + CLI

Урок 07, задание 2. Два файла: модуль со списком задач и консольная программа, которая им пользуется.

## Файлы

- `todo.lua` — твой модуль хранилища задач (файл 1 из 2).
- `main.lua` — CLI, разбирающий команды (файл 2 из 2).

## Задание

### `todo.lua`

Храни задачи в приватной локальной таблице, а счётчик id — в приватной переменной вне функций (номера не переиспользуются даже после удаления).

- `add(text)` — добавить задачу, вернуть её номер. Пустой текст → `nil` и `"пустой текст"`.
- `done(id)` — отметить выполненной. Нет такой задачи → `nil` и `"нет задачи"`.
- `remove(id)` — удалить. Нет такой → `nil` и `"нет задачи"`.
- `list()` — вернуть все задачи массивом таблиц `{id=..., text=..., done=...}` по порядку id.

### `main.lua`

Разбери `arg[1]` (команду) и вызови нужный метод модуля.

- `add "текст"`, `list`, `done <id>`, `remove <id>`.
- `demo` — выполняет сценарий внутри одного запуска: `add ×2 → list → done 1 → list → remove 2 → list`.
- Без аргументов — печатает справку.

Формат строки списка: `[ ] 1: купить молоко` и `[x] 2: выучить модули`.

Сохранение между запусками не требуется. Если модуль вернул `nil` и сообщение — напечатай `Ошибка: ...`.

## Как запускать

```bash
cd lessons/07-modules/tasks/task2_todo
lua main.lua demo
lua main.lua add "купить молоко"
```
