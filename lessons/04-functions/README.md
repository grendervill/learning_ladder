# Урок 04. Функции

## 🎯 Цель
Понять, что функции — значения первого класса, освоить `local function`, `return`, множественные возвраты и `...`.

## 📖 Теория

### 1. Определение и вызов
```lua
-- два равнозначных способа (второй предпочтительнее):
function greet(name)
  return "Привет, " .. name .. "!"
end

local function greet2(name)  -- local function: стандарт де-факто
  return "Привет, " .. name .. "!"
end

print(greet("Алекс"))  --> Привет, Алекс!
```

**Всегда пиши `local function`.** Глобальная функция — такой же глобал, как переменная,
со всеми вытекающими проблемами.

### 2. Параметры и `nil`
Лишние аргументы игнорируются, недостающие становятся `nil` — без ошибок!

```lua
local function add(a, b)
  return a + b
end
print(add(2, 3))      --> 5
print(add(2))         --> ОШИБКА: попытка сложить 2 + nil
print(add(2, 3, 100)) --> 5 (лишний аргумент молча отброшен)
```

Защита через значения по умолчанию (та самая идиома `or`):
```lua
local function greet(name)
  name = name or "Гость"   -- если не передали (nil) — подставится "Гость"
  return "Привет, " .. name
end
```

### 3. Множественные возвращаемые значения — суперсила Lua
```lua
local function divmod(a, b)
  return math.floor(a / b), a % b   -- частное и остаток
end

local q, r = divmod(17, 5)
print(q, r)  --> 3    2
```

Ненужные результаты можно игнорировать, а при передаче в другую функцию
разворачиваются только... впрочем, тонкости:
```lua
local function f() return 1, 2, 3 end
print(f())        --> 1  2  3 (все три!)
print({f()})      --> {1} — нет! В конструктор попадает только ПЕРВОЕ?.. нет,
                    -- на самом деле {f()} = {1, 2, 3}. А вот (f()) = 1.
```

> ⚠️ Правило развёртки: вызов в **конце списка** разворачивает все значения,
> в остальных позициях — урезается до одного. Скобки `(f())` тоже урезают до одного.
> ```lua
> local function f() return 1, 2, 3 end
> print(f(), 0)      --> 1  0   (f() не в конце — урезана!)
> print(0, f())      --> 0  1  2  3 (в конце — развернулась)
> local x = (f())    --> x = 1 (скобки урезают)
> ```

### 4. Vararg: переменное число аргументов `...`
```lua
local function sum(...)
  local total = 0
  for _, v in ipairs({...}) do  -- {...} собирает аргументы в таблицу
    total = total + v
  end
  return total
end
print(sum(1, 2, 3, 4))  --> 10
```

`select("#", ...)` — количество аргументов, `select(i, ...)` — i-й и дальше.
Нужно, чтобы отличать переданный `nil` от «не передали».

### 5. Область видимости и рекурсия
```lua
-- РЕКУРСИЯ: обязательно local ДО function, иначе функция себя не увидит!
local fact            -- сначала объявление...
fact = function(n)    -- ...потом присваивание
  if n <= 1 then return 1 end
  return n * fact(n - 1)
end
-- Короткая запись того же: local function fact(n) ... end
-- (именно поэтому local function — стандарт: с ней рекурсия работает сразу)
print(fact(5))  --> 120
```

### 6. Функции как значения
Функцию можно положить в переменную, передать аргументом, вернуть из функции:
```lua
local function apply(f, x) return f(x) end
print(apply(function(v) return v * 2 end, 21))  --> 42
```
Анонимная функция `function(v) ... end` — обычная практика (колбэки!). Больше — в уроке 09.

## ✅ Запомнить
- `local function` — всегда. Недостающие аргументы = `nil`.
- Функция может вернуть несколько значений; разворачиваются в конце списка.
- `...` — переменное число аргументов, `{...}` — собрать в таблицу.
- Рекурсия требует `local function` (или предварительного объявления).
