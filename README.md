## Правила работы (прочитай внимательно!)

### 1. Как проходить урок
1. Открой `README.md` внутри папки урока. Прочитай теорию целиком.
2. Открой папку `tasks/`. Там файлы `task1_*.lua`, `task2_*.lua`...
3. В каждом файле — комментарий с заданием и заготовка (функция-пустышка с `TODO`).
4. Допиши код прямо в этом файле.
5. Запусти: `lua lessons/XX-.../tasks/task1_*.lua`
6. Когда всё работает — позови меня: **«Проверь урок 03»**. Я проверю и выставлю честную оценку.

### 2. Как я работаю как ментор
- ❌ **Никогда не даю готовый код** под твою задачу. Даже если попросишь.
- ✅ Даю **наводящие вопросы и направление**: «копай в сторону `..` для склейки строк», «что вернёт `#t`, если в середине `nil`?».
- ✅ Разбираю твои ошибки по коду, который ты прислал.
- ✅ Ставлю оценки честно: 2 (не сделано), 3 (с подсказками), 4 (хорошо), 5 (отлично, сам).
- ✅ Веду учёт твоего прогресса (спрашивай: «какой у меня прогресс?»).

### 3. Как запускать Lua (у тебя уже всё стоит)
У тебя установлены `Lua 5.5.1` и `LuaJIT`. Мы учимся на обычном `lua`.

```bash
# Интерактивный режим (REPL) — экспериментируй прямо тут:
lua

# Выход из REPL:
# Ctrl+D (macOS/Linux) или Ctrl+Z, Enter (Windows)

# Запуск файла:
lua lessons/01-hello-lua/tasks/task1_hello.lua

# Проверка версии:
lua -v
```

> ⚠️ Версии Lua: 5.1 (самая старая, ещё живёт в играх), 5.3/5.4/5.5 (современные).
> Различия, о которых скажу по ходу: целочисленное деление `//`, битовые операторы,
> `goto`, `integer`/`float`. Твой код я проверяю на `lua 5.5.1`.

### 4. Система оценок
| Оценка | Что значит |
|---|---|
| 2 | Задание не работает / списано / без понимания |
| 3 | Работает, но с моими сильными подсказками или с ошибками стиля |
| 4 | Работает самостоятельно, мелкие недочёты |
| 5 | Чисто, идиоматично, с пониманием «почему так» |

Для перехода на следующую ступень нужен **минимум 4**. Иначе — доработка.

## 🖥️ Локальный сайт курса

В папке живёт учебный кабинет: программа, теория, вопросы, редактор Lua с LSP,
запуск кода, графический предпросмотр LÖVE и учитель-наставник.

Запуск:

```bash
./scripts/start.sh
```

Скрипт проверит Node, соберёт интерфейс и откроет
[http://127.0.0.1:4173](http://127.0.0.1:4173).

Что нужно для полной версии:

- Node 26+;
- `lua` 5.5.1 (запуск заданий);
- `lua-language-server` (подсказки и диагностика);
- установленный и настроенный OpenCode (учитель-наставник).

Если `lua-language-server` или OpenCode недоступны, сайт продолжит работать:
редактор, запуск кода и материалы останутся на месте, а сдача покажет понятную
ошибку.

Полезные команды:

```bash
npm run dev        # режим разработки
npm test           # тесты
npm run test:e2e   # браузерные сценарии
npm run build      # production-сборка
```

Контент читается из `lessons/` и `course/` на лету: новый раздел теории,
файл задания или квиз подхватываются без перезапуска. Новая папка урока
появится в разделе «Новые материалы», и учитель распределит её по главам.
