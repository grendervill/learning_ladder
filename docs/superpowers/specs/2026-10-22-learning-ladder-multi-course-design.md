# Learning Ladder — курсы-карточки, папка проекта и конструктор

Дата: 2026-10-22  
Статус: согласовано, к реализации  
Рабочая папка: `/Volumes/Samsung/projects/learninglua`

## 1. Зачем это

Сейчас приложение — один курс по Lua под брендом «Лестница Lua». Нужен общий
учебный кабинет «Лестница обучения»: на главной лежат крупные карточки разных
курсов, каждый курс имеет своего наставника и свои настройки, а новый курс можно
собрать по запросу через ИИ.

Главная задача — сохранить ощущение личного кабинета: карточки, курс, урок,
наставник. Всё остальное — обслуживание этого маршрута.

## 2. Цели

1. Убрать Lua из названия приложения и бренда. Сайт и Tauri-приложение —
   «Лестница обучения».
2. Главная — сетка больших карточек курсов: описание, тема, иконка, число
   уроков, прогресс. При наведении — подъём, свечение по контуру за курсором и
   лёгкий наклон карточки.
3. Поиск по карточкам и пагинация по 25 карточек на страницу.
4. Поддержка нескольких курсов. Существующий курс Lua остаётся одной из карточек,
   его прогресс, код-практика, LSP и запуск сохраняются.
5. У каждого курса — свои настройки: наставник, язык/рантайм, LSP, команда
   запуска, тема карточки. Глобальные настройки — только то, что относится ко
   всей программе.
6. Настраиваемая папка проекта — корень, где лежат настройки, промпты, курсы,
   прогресс и отчёты. При пустом проекте на главной показывается плашка с путём
   и кнопкой «Изменить папку проекта».
7. Создание курса через ИИ: тема → уточняющие вопросы с вариантами и своим
   ответом → объём (короткий / средний / длинный) → сборка с прогрессом.
8. Вкладка «Конструктор» — редактируемый промпт, по которому ИИ создаёт карточку
   и наполняет курс в едином стиле.
9. Практика:
   - гуманитарные и прочие не-код темы — квиз 50/50: половина тестовых вопросов,
     половина развёрнутых ответов;
   - математика — квиз + решение по шагам (формула + пояснение, палитра формул,
     предпросмотр);
   - программирование — квиз + редактор кода, LSP и запуск, как у Lua.
10. Сохранить успеваемость, отчёты занятий, проверки, настройки нейросети и
    Tauri-приложение.

## 3. Не-цели и границы

- Многопользовательский режим, аккаунты, облако.
- Генерация картинок для карточек: только фиксированная палитра и набор иконок.
- Распознавание рукописных фото и рисование от руки.
- Редактирование содержимого сгенерированных уроков в интерфейсе (только
  настройки курса и промпт наставника).
- Удаление курсов в первой версии.
- Потоковая генерация по токенам: прогресс через опрос статуса.
- Квизы глав у сгенерированных курсов: только квизы уроков. У Lua квиз главы
  остаётся.

## 4. Папка проекта

### Что это

Корень данных, с которым работает программа. Внутри:

```
<project>/
  data/
    settings.json          # сеть, ключи, общие настройки
    learninglua.db         # прогресс, попытки, сессии
    workspaces/            # временные файлы запуска кода
  prompts/
    constructor.md         # промпт конструктора
  courses/
    lua/
      course.json          # метаданные, настройки, наставник
      course/              # chapters.json, квизы глав
      lessons/             # уроки, задания, README
    <generated-id>/
      course.json          # метаданные, настройки, главы, уроки
      mentor.md            # промпт наставника курса
  reports/                 # итоги занятий
```

`course.json` встроенного Lua-курса описывает метаданные и настройки, а
содержимое читается из `course/` и `lessons/` — так сохраняются существующие
Markdown-файлы, задания и прогресс.

### Миграция

- Текущий репозиторий становится папкой проекта по умолчанию.
- `lessons/` переносится в `courses/lua/lessons/`.
- `course/` переносится в `courses/lua/course/`.
- Создаётся `courses/lua/course.json` с метаданными и настройками; тело текущего
  промпта из `.opencode/agents/lua-mentor.md` переносится в
  `courses/lua/mentor.md`.
- ID уроков и глав не меняются, поэтому существующий прогресс в SQLite
  сохраняется.
- Ссылки в корневом README обновляются на `courses/lua/lessons/...`.
- `PROGRESS.md`, `data/` и `reports/` остаются в корне проекта.

### Переключение

- Путь к текущей папке проекта хранится вне проекта — в конфиге приложения
  (`~/Library/Application Support/learning-ladder/config.json` на macOS).
- Смена папки переключает весь рабочий контекст: настройки, БД, курсы, промпты,
  отчёты. Старая папка не изменяется.
- После переключения интерфейс перезагружается, чтобы не осталось старых кэшей.
- Новая пустая папка создаётся с подкаталогами `data/`, `prompts/`, `courses/`,
  `reports/`; на главной показывается пустое состояние.
- В Tauri папка выбирается нативным диалогом; в браузере — полем пути с проверкой.

### Пустая главная

Если курсов нет и поиск пуст, показывается плашка:

> Курсы создаются каждый в своей папке внутри папки проекта: `<путь>`.
> [Изменить папку проекта] [Создать первый курс]

## 5. Пользовательские сценарии

### Главная

- Шапка: «Лестница обучения», короткий девиз, поиск, кнопка «Создать курс».
- Сетка карточек: 2 колонки на десктопе, 1 на мобильном, до 25 на страницу.
- Карточка: акцент темы, иконка, название, описание, главы/уроки, прогресс,
  «Начать» / «Продолжить». В конце — карточка «Создать курс».
- Поиск фильтрует по названию и описанию; пагинация — страницы по 25.
- Если поиск ничего не нашёл, показывается «Ничего не найдено» (не плашка
  проекта).

### Страница курса

- Шапка в акценте курса: иконка, название, описание, прогресс, «Продолжить»,
  шестерёнка настроек курса.
- Список глав и уроков со статусами.
- Сайдбар: «Все курсы», затем главы текущего курса; внизу — успеваемость,
  настройки.

### Урок

- Lua и программирование: теория, вопросы, практика с кодом и запуском.
- Математика: теория, вопросы, практика с шагами решения.
- Гуманитарные: теория, практика — квиз 50/50. Отдельной вкладки «Вопросы» нет.
- «Сдать урок» отправляет ответы/код/шаги наставнику курса.

### Создание курса

1. Тема: поле + примеры.
2. Уточнение: ИИ предлагает 2–3 вопроса с вариантами (чекбоксы/один выбор) и
   своим ответом; отдельно — объём:
   - короткий: 2–3 урока;
   - средний: 4–6 уроков;
   - длинный: 8–12+ уроков, если тема обширная.
3. Сборка: прогресс, список названий уроков. Мастер открыт до конца; «Отменить»
   прерывает сборку между шагами; ошибка показывается с кнопкой «Повторить».
4. Готово: «Открыть курс». Карточка появляется на главной.

Если уточняющие вопросы не удались, показываются запасные вопросы о цели,
уровне и формате.

### Настройки

Глобальные вкладки:

- **Проверки** — сервер, Node, папка проекта, БД, материалы, OpenCode, сеть.
- **Нейросеть** — провайдер, ключ, модель, уровень размышлений, проверка связи.
- **Создать курс** — описание сценария, выбранная модель, кнопка «Открыть мастер».
- **Конструктор** — промпт создания карточки/курса, «Вернуть стандартный».
- **Папка проекта** — текущий путь, число курсов, «Изменить папку проекта».

Настройки курса (отдельная страница/модальное окно с шестерёнкой):

- **Основное** — название, описание, тема, иконка.
- **Наставник** — промпт курса.
- **Практика** — режим (гуманитарный / математика / программирование), язык,
  расширение файла, команда запуска, команда и аргументы LSP.
- **Проверки курса** — доступность рантайма и LSP, ошибки материалов.

Всё, что относится к курсу, переносится из глобальных настроек сюда.

## 6. Модель курса

### Метаданные

`id`, `title`, `description`, `theme`, `icon`, `createdAt`, `builtIn`,
`mode` (`general` | `math` | `programming`), `settings`.

`theme`: forest, amber, ocean, plum, clay.  
`icon`: book, code, chart, globe, atom, scale, palette, heart.

### Содержимое

- Главы и уроки как сейчас: теория, квиз, практика.
- `courseId` у главы и урока.
- Lua: `courseId = "lua"`, ID уроков не меняются.
- Сгенерированные курсы: 2–6 глав, в каждом уроке теория, квиз и практика
  согласно режиму курса.
- Квизов глав у сгенерированных курсов нет. Глава считается пройденной после
  всех уроков; у Lua квиз главы остаётся обязательным.

### Практика

- `code`, `terminal`, `love`, `project` — Lua/программирование.
- `quiz` — квиз 50/50 для гуманитарных курсов.
- `steps` — математика: шаги `{formula, explanation}` + финальный ответ.
- Программирование: квиз + код с запуском и LSP, как у Lua.

### Рантаймы

Пресеты с проверкой установленных инструментов:

| Язык | Запуск | LSP | Расширение |
|---|---|---|---|
| Lua | `lua {file}` | `lua-language-server` | `.lua` |
| C | `gcc {file} -o {bin} && {bin}` | `clangd` | `.c` |
| C++ | `g++ {file} -o {bin} && {bin}` | `clangd` | `.cpp` |
| Python | `python3 {file}` | `pyright-langserver --stdio` | `.py` |
| JavaScript | `node {file}` | `typescript-language-server --stdio` (если установлен) | `.js` |
| Свой | команда пользователя | команда пользователя | `.txt`/своё |

Команды запуска и LSP хранятся в настройках курса и проверяются отдельно.
Для сгенерированных курсов конструктор выбирает пресет по теме; пользователь
может изменить его в настройках курса.

## 7. Хранение и API

- Курсы: `<project>/courses/<id>/`.
  - Lua — `course.json` + `course/` + `lessons/`.
  - Сгенерированные — `course.json` + `mentor.md`.
- Глобальные настройки: `<project>/data/settings.json`.
- Промпт конструктора: `<project>/prompts/constructor.md`.
- БД: `<project>/data/learninglua.db`; схема не меняется, ID глобально уникальны.
- Доступ считается отдельно для каждого курса.
- После генерации — перечитывание курсов и событие `course:changed`.

API:

- `GET /api/project` — путь, число курсов, состояние.
- `PUT /api/project` — переключить папку проекта.
- `GET /api/courses?query=&page=&pageSize=25` — карточки, поиск, пагинация.
- `GET /api/courses/:id` — содержимое курса и доступ.
- `GET/PUT /api/courses/:id/settings` — настройки курса.
- `GET/PUT /api/courses/:id/mentor-prompt` — промпт наставника.
- `POST /api/courses/clarify` — уточняющие вопросы.
- `POST /api/courses/generate` — запуск сборки.
- `GET /api/courses/jobs/:jobId` — прогресс.
- `POST /api/courses/jobs/:jobId/cancel` — отмена.
- Старые `/api/lessons/:id`, `/api/submit`, квизы и запуск определяют курс по
  уроку и используют настройки этого курса.

### Генерация

1. План: метаданные карточки, `mode`, `settings`, промпт наставника, главы и
   названия уроков.
2. Наполнение: каждый урок отдельным запросом.
3. Валидация JSON после каждого шага; один повтор при ошибке.
4. Запись `course.json` и `mentor.md`, обновление контекста, карточка на главной.
5. Ошибка видна в мастере; битый курс не сохраняется.

Для OpenCode каждый запрос — отдельная сессия с нейтральным агентом
`course-constructor`; для прямых провайдеров — системный промпт. Наставник курса
аналогично использует нейтральный `course-mentor` и промпт курса в запросе.

## 8. Визуальный язык

- Бренд: «Лестница обучения», девиз «курсы, собранные под тебя».
- Типографика и палитра сайта сохраняются: Literata, Golos Text, JetBrains Mono,
  тёмно-зелёный сайдбар, светлая бумага.
- Карточки — главный объект: крупное имя, спокойное описание, тонкая линия
  прогресса, иконка в акцентном круге.
- Свечение по контуру следует за курсором через CSS-переменные `--mx`, `--my`;
  наклон `rotateX/rotateY` ±4°, подъём и мягкая тень. При
  `prefers-reduced-motion` — без наклона.
- Никаких сгенерированных картинок: тема, иконка, типографика.

## 9. Решения

- Гуманитарные курсы: практика — квиз 50/50, отдельной вкладки «Вопросы» нет.
- Математика: квиз + шаги; программирование: квиз + код с запуском.
- Глава сгенерированного курса закрывается после всех уроков; у Lua квиз главы
  обязателен.
- Один общий провайдер/модель; промпт наставника — у курса.
- Учебная сессия глобальная; итог нейтральный, с разбивкой по курсам.
- Во время сборки мастер открыт; отмена прерывает job; фонового списка задач нет.
- Нет удаления курсов и ручного редактирования уроков в первой версии.
- Текущий репозиторий — проект по умолчанию; Lua переносится в `courses/lua`.

## 10. Риски

- **Битый JSON.** Схема + повтор + отказ от сохранения.
- **Долгая генерация.** Прогресс, отмена между шагами, ошибка с повтором.
- **Смешивание тем.** Свежая сессия на каждый запрос, промпт и контекст курса.
- **Старый прогресс.** ID Lua-уроков не меняются.
- **Смена папки.** Перезагрузка контекста и интерфейса; старые данные не трогаем.
- **Разные LSP/рантаймы.** Пресеты, проверки, предупреждение при отсутствии
  инструмента; редактор работает и без LSP.
- **Переименование Tauri.** Пересобрать, заменить старую иконку, проверить
  холодный старт.

## 11. Проверка

- Юнит-тесты: миграция/загрузка курсов, поиск и пагинация, доступ по курсам,
  валидация плана/уроков, изоляция промптов, 50/50-квиз, шаги, рантаймы.
- E2E: главная с карточками и поиском, пустая папка, создание курса с замоканным
  ИИ, письменная практика, код с запуском, настройки курса и проекта.
- Визуально: карточки Light/Dark, наведение/наклон, мастер, страница курса,
  настройки, окно Tauri.
- `npm test`, `npm run test:e2e`, `npm run typecheck`, `npm run build`,
  `npm run tauri:build`.
